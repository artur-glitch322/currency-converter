# 💱Конвертер валют<br>
## 📝Автор: Артур Карамов<br><br>
### 📌Описание:
GUI-приложение для конвертации валют с использованием API, сохранением истории и валидацией ввода.
### 🔑Получение API-ключа:
1. Перейдите на [exchangerate-api.com]();
2. Зарегистрируйтесь по почте и получите бесплатный ключ;
3. Вставьте ключ в переменную `API_KEY` в currency_converter.py.
### ▶️Инструкция по запуску:
1. Установите Python (если нет)
2. В папке со скачанным проектом запустить команду для установки недостающих библиотек (requests):
    `pip install -r requirements.txt`
3. Запустите приложение (или файл `main.py`) через IDE или выполните следующую команду в консоли:<br>
    `python main.py`
### 📃Примеры использования:
1. #### 💱Конвертация валют:
   1. Выберите из какой в какую валюту конвертировать;
   2. Укажите сумму (обязательно больше нуля);
   3. Нажмите конвертировать, после чего под кнопкой появляется результат и записывается в историю конвертаций (в файл и таблицу в окне программы).
2. #### 🗑️Очистка истории:
    1. Под таблицей истории нажмите кнопку "🗑 Очистить";s
    2. Подтвердите очистку во всплывающем окне, после чего файл и таблица очистятся.
3. #### 🔄Обновить валюты:
    1. Под таблицей с историей нажмите кнопку "🔄Обновить валюты", после чего обновится список валют для конвертации.
### ❌Возможные ошибки:
   1. #### Пустое поле суммы:
      1. При попытке сконвертировать с пустым полем суммы вызывает окно с ошибкой:<center>**_Введите сумму!_**</center>и не дает провести конвертацию;
   2. #### Сумма меньше нуля:
      1. При поптытке сконвертировать сумму меньше нуля вызывает окно с ошибкой: <center>**_Сумма должна быть положительным числом!_**</center>и не дает провести конвертацию;
   3. #### Ошибка получения данных с API:
      1. При недоступности списка валют вызывает окно с ошибкой:<center>**_Не удалось загрузить курсы:<br>Используем базовые валюты_**</center> и устанавливает следующий список по умолчанию для конвертации:\
      `["USD", "EUR", "RUB", "GBP", "JPY", "CNY", "KZT", "CAD", "AUD"]`
      2. При недоступности API вызывает окно с ошибкой:<center>**_Не удалось конвертировать<br>Ошибка API_**</center>
