Конвертер валют:

Автор: Артур Карамов

Описание:

GUI-приложение для конвертации валют с использованием API, сохранением истории и валидацией ввода.

Получение API-ключа:

1. Перейдите на exchangerate-api.com
2. Зарегистрируйтесь по почте и получите бесплатный ключ
3. Вставьте ключ в переменную API_KEY в currency_converter.py
